## How to Run the River Flow Forecasting Dashboard

### Requirements

The following software is required:

* Python 3.x
* Internet connection
* A web browser
* GitHub access

### Step 1: Download the Project

Open the project's GitHub repository and click **Code → Download ZIP**.

Extract the downloaded file to a suitable location on the computer.

### Step 2: Open the Project Folder

Open Command Prompt and navigate to the project folder.

Example:

```bash
cd "C:\Users\YourName\Downloads\River_Flow_Forecasting"
```

### Step 3: Install the Required Dependencies

Run the following command:

```bash
pip install -r requirements.txt
```

This installs all the Python libraries required by the dashboard.

### Step 4: Start the Dashboard

Run:

```bash
streamlit run app.py
```

### Step 5: Open the Dashboard

After Streamlit starts, open the following address in a web browser:

```text
http://localhost:8501
```

The River Flow Forecasting Dashboard will then be available and ready to use.

### Alternative: Online Dashboard

If the dashboard has been deployed using Streamlit Community Cloud, users do not need to install Python or any dependencies.

They can simply open the provided Streamlit dashboard URL in a web browser and use the system directly.
